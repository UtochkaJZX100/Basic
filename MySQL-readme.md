1) Установить пакеты: apt install -y mysql.
2) Подключиться к репозиторию и скачать файлы для восстановления: git pull origin MySQL.
3) Запустить на Master скрипт master-bc.sh: происходит замена конфига, создаётся пользователь для реплики с добавлением прав доступа.
4) Запустить на Slave скрипт slave-bc.sh: происходит замена конфига, репликация останавливается, настраивается и запускается.
